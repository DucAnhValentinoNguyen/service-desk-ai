# Technician Appointment Policy

This synthetic scheduling policy is included for the service-desk demo. The linked public application-notes page is an example of the type of technical source a production knowledge base could index.

Technician appointments are offered only from available calendar slots. The requester must confirm the selected time. A booking is idempotent and must not replace an existing appointment. If no suitable slot exists, offer alternatives or escalate to a human coordinator.
